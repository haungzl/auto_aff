# Page topology

Shared shell: slim rose announcement strip, white header with logo and horizontal category links, responsive menu, four-column footer. Home: split hero, three trending cards, four category sections with four cards each, closing editorial callout. Archive: centered serif title, rule-separated section heading, four-column card grid. Article: breadcrumb, category, headline and dek, byline and disclosure, large cover photograph, editorial body, merchant box, sidebar, related cards. Trust pages: centered reading column.

Responsive: four-column grids become two columns below 1000px and one below 440px. Header becomes a menu below 720px. Hero stacks image before text below 720px. Article sidebar disappears below 720px.
